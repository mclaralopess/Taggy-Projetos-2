# TagGreen

Solução desenvolvida para calcular e comunicar o impacto ambiental evitado por usuários ao utilizarem sistemas de pagamento automático em pedágios e estacionamentos. A proposta consiste em uma calculadora que estima a redução de emissões de carbono e o consumo de papel, tornando esses dados visíveis e acessíveis para os clientes.
